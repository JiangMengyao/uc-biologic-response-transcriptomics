# Upload checklist

1. Open `https://github.com/JiangMengyao/uc-biologic-response-transcriptomics` while signed in.
2. Choose **Add file → Upload files**.
3. Drag every file and folder from this directory into the browser. Do not upload the parent directory itself.
4. Confirm that the root of the repository contains `README.md`, `.gitignore`, `CITATION.cff`, `scripts/`, `config/`, `docs/`, `environment/`, and `results/`.
5. Commit with the message: `Add reproducible analysis workflow and source data`.
6. Open the repository in a private/incognito browser window and check that the README renders and no `data/raw/`, `.h5ad`, `.rds`, `.gz`, `submission/`, or `manuscript/` files are present.

After the first commit, the permanent repository URL is:

`https://github.com/JiangMengyao/uc-biologic-response-transcriptomics`

Optional DOI: connect the repository to Zenodo, create a GitHub Release (for example, `v1.0.0`), then add the DOI supplied by Zenodo to the manuscript before submission. Do not create a release until the repository contents have been checked.
